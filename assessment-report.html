JSON-blob (permukaan tulis legacy)app_data: kelas_v1 · siswa_v1 · presensi_v1 · modulAjar_v1Kompatibilitas — penulis lama (roster, user management) tetap menulis di sini; trigger menyinkronkan proyeksi + revision secara atomik

Kekuatan

  • Proyeksi relasional untuk 4 koleksi akademik dengan index (kelas/status/tanggal/siswa/jurusan), constraint NOT NULL, FK, dan CHECK JSON.
  • Optimistic concurrency: revision + header If-Match/X-Collection-Revision; tulis usang ditolak 409 dan client me-refresh (hook).
  • Validasi ketat per koleksi (duplikat ID/NISN/key presensi, format tanggal/waktu/status, struktur modul) — rusak terdeteksi, tidak diam-diam di-seed.
  • Migrasi additive/idempotent + backfill; fallback aman ke app_data bila proyeksi absen.
  • Sesi: token hash SHA-256, TTL 7 hari; audit trail presensi & aksi admin.

Risiko / Saran

  • Tulis tetap lewat app_data JSON (trigger memproyeksikan) → proyeksi dihitung ulang penuh per tulis; untuk presensi besar pertimbangkan tulis langsung ke tabel.
  • Kolom any di beberapa handler → kehilangan type-safety; sarankan tipe hasil query.
  • Belum ada backup/jadwal ekspor D1 otomatis; migrasi 0018 remote menunggu operator.

Penilaian ini berbasis pembacaan langsung kode (App.tsx, middleware, auth.ts, rate-limit, data/[key].ts, relational-data.ts, usePersistedCollection, navItems, migrations, vite.config) plus verifikasi ulang: npx vitest run --testTimeout=10000 → 42 file/235 test aplikasi + 8 test sync-worker, 100% lulus; npx vite build → sukses, migrasi 0022 lulus lokal, dan roundtrip 87 siswa produksi terverifikasi. Migrasi 0017–0022 telah diterapkan ke D1 remote (backup sebelum 0021: /tmp/opencode/backup-produksi-cbt-0021.sql; sebelum 0022: backup-produksi-cbt-0022-20260816-142040.sql). Smoke test produksi 16 Agustus 2026: fitur min-submit terverifikasi — ujian resmi submit awal ditolak 409 lalu diterima 200 setelah waktu minimal, latihan bebas kirim, tombol runner terkunci dengan countdown (Playwright); simulasi skala besar nyata: UAS 45 soal (40 PG + 5 essai) skor 100 dan latihan 30 soal (25 PG + 5 essai) skor 100, attempt simulasi dibersihkan dari produksi. Aktivasi provider nyata (QR WhatsApp, deploy Apps Script) tetap menunggu langkah operator.
